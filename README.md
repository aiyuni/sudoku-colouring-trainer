# Sudoku Trainer/Solver

A sudoku web app to learn how to solve sudoku using logical, human-friendly Colouring techniques, instead of raw brute force or trial and error.   Provides functionality to generate specifically-designed puzzles to practice applying these techniques.  

The solver implements the two highly popular and documented Colouring techniques: [Simple Colouring](https://www.sudokuwiki.org/Simple_Colouring) and [3D Medusa](https://www.sudokuwiki.org/3D_Medusa), but more importantly introduces a novel, undocumented improvement of 3D Medusa called **Dragon Colouring**. 
Dragon Colouring will solve almost every puzzle rated Beyond Hell on [Sudoku.Coach](https://sudoku.coach/en/home). 

User can upload puzzle strings generated from [Sudoku.Coach](https://sudoku.coach/en/home) and [SudokuWiki](https://www.sudokuwiki.org/Main_Page) to this solver to practice.  

Claude code was used to implement this app.
