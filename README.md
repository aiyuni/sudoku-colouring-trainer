# Sudoku Trainer/Solver

A sudoku web app to learn how to solve sudoku using logical, human-friendly Colouring techniques, instead of raw brute force, backtracking, or trial and error.   Provides functionality to generate specifically-designed puzzles to practice applying these techniques.  

The solver implements the two highly popular and documented Colouring techniques: [Simple Colouring](https://www.sudokuwiki.org/Simple_Colouring) and [3D Medusa](https://www.sudokuwiki.org/3D_Medusa), but more importantly implements a novel, undocumented technique called **Dragon Colouring**. 

Whereas the well-known Colouring techniques get stuck at "Hell" puzzles, Dragon Colouring technique solves every "Hell" and "Beyond Hell" puzzle on [Sudoku.Coach](https://sudoku.coach/en/home).   Improvements to the technique is in the works to allow it to solve "Almost Impossible" puzzles. 

User can upload puzzle strings generated from [Sudoku.Coach](https://sudoku.coach/en/home) and [SudokuWiki](https://www.sudokuwiki.org/Main_Page) to this solver to practice Colouring. 

Claude code was used to implement this app.
